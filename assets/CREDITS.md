# Materiali inclusi

- `concrete/`: ambientCG Concrete034.
- `wood/`: ambientCG Wood051.
- Autore: Lennart Demes / ambientCG. Licenza CC0 1.0 Universal.
- Fonti: https://ambientcg.com/view?id=Concrete034 e https://ambientcg.com/view?id=Wood051
- Licenza: https://docs.ambientcg.com/license/

Texture già presenti nel configuratore mostre locale, riutilizzate con relativa licenza. Colore WebP 2048 px, normal map OpenGL e rugosità 1024 px. Nessuna dipendenza di rete a runtime.

Geometrie industriali e texture delle etichette sono create nel codice di questo progetto. Non riproducono uno specifico prodotto commerciale. Le anteprime del catalogo vengono renderizzate dagli stessi modelli della scena.
